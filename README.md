# ButtoBuster（ブットバスター）

敵を剣で吹き飛ばし、壁に叩きつけて場外へ飛ばす 1 人用の 3D アクションゲームです。
Unity のコンポーネント指向の仕組みを C++ と DxLib で作った自作エンジンの上に、ゲームを組み立てています。

- 言語 / ライブラリ：C++17 / DxLib
- 開発環境：Visual Studio 2022（v143、x64）
- 規模：約 19,200 行 / 211 ファイル（うち自作エンジン 約 6,800 行）

## ゲームの決まり

| 決まり | 中身 |
|---|---|
| バースト値 | HP の代わり。攻撃を受けるたびに溜まり、溜まるほど遠くへ飛ぶ。数字は出さず、湯気と赤みで見せる |
| 壁バウンド | 戦える範囲の端は壁。勢いよくぶつかると一瞬張り付き、跳ね返る |
| 壁割り | バースト値が溜まった状態で壁にぶつかると、壁を割って場外へ。敵なら撃破、自分なら負け |
| 連鎖 | 吹き飛んだ敵が砲弾になり、触れた敵も巻き込んで吹き飛ばす |
| ジャスト回避 | 当たる直前の回避で敵がスローになり、踏み込んで反撃できる |
| フェーズ | 敵を全部倒すと次へ。5 フェーズごとに全回復、フェーズ 10 を越えたら勝ち |
| 難易度 | EASY / NORMAL / HARD。自分の許容値、敵の賢さ、同時に攻撃してくる敵の数が変わる。最高記録も難易度ごと |

## 操作

| 操作 | キーボード・マウス | パッド |
|---|---|---|
| 移動 | WASD | 左スティック |
| 視点 | マウス / Q E | 右スティック |
| 攻撃（3 段まで繋がる） | J / 左クリック | X |
| ガード | K / 右クリック | L2 |
| ジャンプ | SPACE | A |
| 対空斬り | 攻撃 + ジャンプ | X + A |
| 溜め斬り（押し続けて溜める） | 攻撃 + ガード | R2 |
| 回避 | ガード + ジャンプ | L1 |
| チュートリアルを飛ばす | Enter 長押し | Start 長押し |

## 動かし方

1. DxLib（VisualC++ 用）を `C:\DxLib_VC` に置く（`C:\DxLib_VC\プロジェクトに追加すべきファイル_VC用` を参照しています）
2. `ButtoBuster/ButtoBuster.sln` を Visual Studio 2022 で開く
3. 構成を `Debug | x64` か `Release | x64` にしてビルド・実行する

## フォルダの構成

```
ButtoBuster/ButtoBuster/
├─ Source/
│  ├─ WinMain.cpp   入口
│  ├─ Engine/       どのゲームにも使える土台（GameObject、物理、描画、音、AI の部品など）
│  └─ Game/         ButtoBuster だけの中身（プレイヤー、敵、フェーズ、チュートリアル、UI など）
└─ Data/            モデル・アニメーション・画像・音
```

Engine/ は Game/ を一切参照しません（依存は Game → Engine の一方通行）。

## 主な設計

| パターン | 使った場所 | なぜ使ったか |
|---|---|---|
| コンポーネント | GameObject + Component | 機能を部品として足し引きする |
| ステート | StateManager&lt;T&gt; / ICharacterState&lt;T&gt; | 行動ごとにクラスを分け、切り替えは予約して処理の後で行う |
| オブザーバー | Subject&lt;E&gt; / Observer&lt;E&gt; | 音や演出を足しても、プレイヤーや進行の処理を書き換えない |
| ストラテジー | InputInfo | 人（PlayerController）と敵（EnemyAI）が同じ処理で動く |
| ビヘイビアツリー | Engine/AI/BehaviorTree.h、EnemyAI | 敵の行動を優先順の枝で選び、賢さの数値で枝を変える |
| データ駆動 | AttackData / EnemyData / PhaseData / DifficultyData / TutorialSteps | 技や敵の違いは表で表し、処理は 1 つにする |
| ファクトリ / ビルダー | PlayerFactory / EnemyFactory / CharacterBuilder | キャラの組み立て手順を 1 か所にまとめる |
| オブジェクトプール | NeedlePool | 針を先に作って使い回す |
| 共有の寿命 | BlowChain（shared_ptr） | 連鎖に関わる全員で持ち、最後の 1 人が手放したら終わる |
| トークン | AttackTokenPool | 同時に攻撃してくる敵の数を限る |

## デバッグ用のキー

F1 でデバッグの一覧を開きます（F2 当たり判定の表示、F3 無敵 など）。
